# Magic Scale Lead Kitchen

Build a professional CRM web application for my company Magic Scale, a restaurant consultancy that provides Swiggy and Zomato onboarding and restaurant growth services.

Create a modern, clean, responsive CRM dashboard with a professional design.

The CRM should include:

Admin login

Dashboard with total leads, new leads, follow-ups, converted leads and lost leads

Lead management with customer name, phone number, restaurant name, city, cuisine, service required, lead source, assigned executive, status and remarks

Lead sources: Manual, Website, CRM Enquiry Page and Advertisement

Lead status: New, Not Called, Call Connected, Interested, Follow-up Required, Quotation Shared, Payment Pending, Converted, Lost and Not Interested

Search, filters and duplicate phone number detection

Executive management for 20+ employees

Manual and automatic round-robin lead assignment

Follow-up management

Reports for executive performance and lead conversion

Important:
Keep the application ready for integration with an external Supabase database owned by Magic Scale. Do not use Lovable Cloud as the permanent database. Do not insert real customer data or expose credentials.

First create the complete frontend design and navigation. We will connect and configure the company-owned Supabase database separately.
